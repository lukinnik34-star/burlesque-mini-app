# Prize Rules

## MVP

В MVP призы моковые. Они нужны для демонстрации пользовательского сценария, а не для реальной экономики.

## Пример MVP-приза

- Название: "Комплимент от Burlesque".
- Промокод: `BURLESQUE10`.
- Тип: моковый промокод.
- Статус: выдан.
- Источник: Scratch Card.

## Правила будущей реализации

- Приз выдается на backend.
- У приза есть срок действия.
- У приза есть статус: выдан, использован, истек, отменен.
- Один игровой сценарий должен иметь лимит попыток.
- Пользователь не должен получать приз бесконечно.
- CRM или админка должна видеть факт выдачи, если это нужно бизнесу.

## Важные ограничения

- Не показывать реальные промокоды в коде фронтенда.
- Не рассчитывать выигрыш на клиенте.
- Не использовать client-side localStorage как источник истины для реальных призов.
- Не привязывать правила призов к конкретному UI-компоненту.
