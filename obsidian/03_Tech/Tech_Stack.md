# Tech Stack

## Frontend

- Next.js.
- React.
- TypeScript.
- Tailwind CSS.
- Telegram Mini App SDK.

## Backend на первом этапе

- Next.js API routes.
- Моковые данные в коде или локальных JSON/TypeScript структурах.
- Отдельные endpoints под мероприятия, профиль, игры и призы можно добавить по мере необходимости.

## База данных позже

- PostgreSQL.
- Prisma.

## CRM позже

- Подключение только через backend.
- Фронт не должен обращаться к CRM напрямую.
- Нужен адаптерный слой, чтобы не привязывать интерфейс к конкретной CRM.

## Авторизация

- Telegram initData обязательно валидировать на backend.
- Фронту нельзя доверять идентичность пользователя.
- Для MVP можно использовать моковые данные, но архитектурно помнить о будущей серверной проверке.

## Причина выбора

Next.js + React + TypeScript дают быстрый старт, удобную структуру страниц и API routes. Tailwind CSS подходит для быстрой сборки мобильного интерфейса. Telegram Mini App SDK нужен для корректной работы внутри Telegram.
