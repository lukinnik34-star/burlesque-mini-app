# CODEX MASTER PROMPT

## Роль Codex в проекте

Ты работаешь над Telegram Mini App для Burlesque. Это рабочее маркетинговое приложение внутри Telegram: мероприятия, промо-игры, призы, профиль, адреса клубов и быстрые действия.

## Главные ограничения MVP

В MVP делаем:

- главную страницу;
- список мероприятий;
- карточку мероприятия;
- раздел игр;
- одну игру Scratch Card;
- моковый приз;
- профиль с моковыми данными;
- адреса клубов;
- нижнюю навигацию;
- моковые данные без CRM.

В MVP не делаем:

- реальную CRM-интеграцию;
- оплату;
- сложную админку;
- несколько игр сразу;
- сложную систему лояльности;
- реальные SMS;
- реальный продакшен-деплой.

## Техническое направление

- Frontend: Next.js + React + TypeScript.
- Styling: Tailwind CSS.
- Telegram Mini App SDK.
- Backend первого этапа: Next.js API routes.
- База позже: PostgreSQL + Prisma.
- CRM позже и только через backend.
- Telegram initData обязательно валидировать на backend.

## Правила работы

- Не раздувай MVP.
- Не добавляй лишние библиотеки без причины.
- Сохраняй mobile-first подход.
- Делай интерфейс как приложение внутри Telegram, а не как сайт.
- Учитывай темный premium nightlife стиль Burlesque.
- Не доверяй фронтенду в вопросах пользователя, баллов, призов и промокодов.
- Если задача требует решения, фиксируй его в `obsidian/06_Production/Decisions_Log.md`.
- Если появляется будущая задача, добавляй ее в `obsidian/06_Production/Backlog.md`.
