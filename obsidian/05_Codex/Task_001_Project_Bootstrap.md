# Task 001: Project Bootstrap

## Контекст

Проект Burlesque Telegram Mini App уже имеет структуру:

- `app/`
- `obsidian/`

Документация проекта находится в `obsidian/`. Перед началом задачи обязательно прочитать:

- `obsidian/00_Project_Hub.md`
- `obsidian/01_Product/MVP.md`
- `obsidian/03_Tech/Tech_Stack.md`
- `obsidian/05_Codex/CODEX_MASTER_PROMPT.md`

## Цель

Создать базовый Next.js проект в папке `app/` для будущей реализации Telegram Mini App.

## Входит в задачу

- Инициализировать Next.js проект в `app/`.
- Использовать TypeScript.
- Подключить Tailwind CSS.
- Подготовить базовую структуру для mobile-first приложения.
- Убедиться, что проект запускается локально.
- Не реализовывать полноценные экраны продукта на этом шаге.

## Не входит в задачу

- Не делать CRM-интеграцию.
- Не подключать PostgreSQL и Prisma.
- Не реализовывать Scratch Card.
- Не делать админку.
- Не делать продакшен-деплой.
- Не добавлять оплату.
- Не раздувать стартовый шаблон.

## Технические требования

- Next.js.
- React.
- TypeScript.
- Tailwind CSS.
- Структура должна быть удобной для будущих features: events, games, profile, clubs.
- Секреты и приватные ключи не добавлять.

## Дизайн-направление для стартового экрана

Если стартовая страница будет создана, она должна быть простой:

- темный фон;
- теплый акцент;
- mobile-first контейнер;
- без маркетинговой лендинговой структуры;
- без лишних секций.

## Критерии готовности

- В папке `app/` создан Next.js проект.
- TypeScript работает.
- Tailwind CSS подключен.
- Локальный запуск проходит без ошибок.
- Codex написал краткий отчет.
