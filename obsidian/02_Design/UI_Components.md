# UI Components

## Базовые компоненты MVP

### App Shell

- Полноэкранный mobile-first layout.
- Контентная область.
- Нижняя навигация.
- Учет safe-area на мобильных устройствах.

### Bottom Navigation

Вкладки MVP:

- Главная.
- Афиша.
- Игры.
- Адреса.
- Профиль.

Требования:

- Фиксированная нижняя навигация.
- Понятные иконки.
- Активное состояние.
- Достаточная высота для нажатия пальцем.

### Event Card

Содержит:

- изображение или визуальную заглушку;
- название мероприятия;
- дату и время;
- короткое описание;
- клуб или адрес;
- CTA "Подробнее" или "Забронировать".

### Event Detail

Содержит:

- крупный визуальный блок;
- название;
- дату;
- место;
- описание;
- кнопки "Забронировать", "Открыть сайт", "Позвонить".

### Game Card

Содержит:

- название игры;
- короткий статус;
- CTA "Играть";
- визуальный акцент.

### Scratch Card

Содержит:

- область карточки для стирания;
- состояние до игры;
- состояние результата;
- приз или промокод;
- кнопку возврата или перехода в профиль.

### Profile Summary

Содержит:

- имя пользователя;
- аватар или заглушку;
- баллы;
- внутреннюю валюту;
- список моковых призов.

### Club Address Card

Содержит:

- название клуба;
- адрес;
- режим или краткую подпись;
- кнопки: карта, маршрут, такси, позвонить.
