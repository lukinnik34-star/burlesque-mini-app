# Feature List

## P0: MVP

- Главная страница.
- Список мероприятий.
- Карточка мероприятия.
- Раздел игр.
- Scratch Card.
- Моковая выдача приза.
- Профиль с моковыми данными.
- Баллы или внутренняя валюта моковыми значениями.
- Адреса клубов.
- Быстрые действия.
- Нижняя навигация.
- Telegram Mini App SDK.
- Backend API routes для будущей валидации и моковых endpoints.

## P1: После MVP

- Реальная серверная валидация Telegram initData.
- Хранение пользователей в PostgreSQL.
- Хранение выданных призов.
- История игр.
- Ограничение повторного получения призов.
- Подключение Prisma.
- Подготовка CRM-адаптера на backend.
- Улучшенная аналитика событий.

## P2: Расширение продукта

- Wheel Of Prizes.
- Дополнительные промо-механики.
- Настоящая система лояльности.
- Сегментация пользователей.
- Персональные предложения.
- Админка для мероприятий и призов.
- Интеграция с CRM.
- Интеграция с рассылками.

## P3: Долгосрочно

- Онлайн-оплата или депозит, если будет бизнес-потребность.
- Реферальные механики.
- Более глубокая персонализация.
- A/B тесты промо-механик.
- Мультигородская структура, если появится необходимость.
