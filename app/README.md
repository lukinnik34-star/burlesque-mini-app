# Burlesque Telegram Mini App

Базовый Next.js проект для будущего Telegram Mini App Burlesque.

## Стек

- Next.js
- React
- TypeScript
- Tailwind CSS
- App Router

## Запуск

```bash
npm run dev
```

После запуска открыть:

```text
http://localhost:3000
```

## Проверка

```bash
npm run lint
npm run build
```

## Структура

```text
src/app/          Next.js App Router
src/components/   общие UI-компоненты
src/features/     будущие продуктовые разделы
src/lib/          утилиты и mock data
src/types/        общие TypeScript-типы
```

## Ограничения текущего шага

На этапе bootstrap не реализованы CRM, игры, авторизация, база данных и бизнес-логика. Проект содержит только стартовую страницу и базовую структуру для следующих задач MVP.
